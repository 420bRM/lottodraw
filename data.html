로또 당첨번호 데이터 (JSON · CSV)

로또 6/45 1회부터 최신 회차까지 당첨번호와 1~5등 당첨금을 JSON 파일로 무료 제공합니다. 가입이나 키 없이 바로 받을 수 있고, 앱 · 엑셀 · 블로그 · 연구 어디에 쓰셔도 됩니다. 쓰실 때 출처로 lottodraw.kr 링크를 남겨 주십시오.

매주 토요일 추첨 결과가 나오면 자동으로 갱신됩니다.

파일 주소

파일담긴 것
https://www.lottodraw.kr/lotto-data.json 회차, 추첨일, 당첨번호 6개, 보너스 번호, 1등 당첨자 수, 1등 1게임당 당첨금
https://www.lottodraw.kr/prize-data.json 2~5등 당첨 게임 수와 1게임당 당첨금, 회차 판매액

다른 사이트의 웹 페이지에서도 바로 불러올 수 있습니다(CORS 허용). 두 파일 모두 최신 회차가 맨 앞에 옵니다.

CSV(엑셀)로 받기

두 파일을 회차별로 합쳐 CSV 파일 하나로 내려받습니다. 엑셀에서 바로 열립니다.

갱신 시점

추첨은 매주 토요일 오후 8시 35분입니다. 결과가 나오면 보통 그날 밤 새 회차가 들어가고, 늦어도 일요일 새벽에는 들어갑니다. 1등 금액이 늦게 확정되는 경우를 대비해 월요일 오전까지 최근 회차를 한 번 더 확인합니다. 자동으로 받는 프로그램이라면 토요일 밤이나 일요일 · 월요일에 한 번 받으면 충분합니다 — 몇 분마다 받을 필요는 없습니다.

형식

lotto-data.json

{
  "totalDraws": 1245,
  "lastUpdated": "2026-10-10",
  "draws": [
    {
      "round": 1245,
      "date": "2026-10-10",
      "numbers": [4, 5, 25, 28, 32, 42],
      "bonus": 12,
      "firstPrizeWinners": 10,
      "firstPrizeAmount": 3006515775
    },
    …
  ]
}
항목뜻
totalDraws들어 있는 회차 수
lastUpdated마지막으로 반영한 추첨일 (YYYY-MM-DD)
draws회차 목록. 최신 회차가 맨 앞
round회차
date추첨일 (YYYY-MM-DD)
numbers당첨번호 6개, 작은 수부터
bonus보너스 번호
firstPrizeWinners1등 당첨 게임 수. 0이면 1등이 없어 이월된 회차
firstPrizeAmount1등 1게임당 당첨금 (원, 세전). 1등이 없으면 0

prize-data.json

{
  "lastUpdated": "2026-10-10",
  "draws": [
    { "round": 1245, "w2": 91, "a2": 55064392, "w3": 3102, "a3": 1615365,
      "w4": 163177, "a4": 50000, "w5": 2786728, "a5": 5000, "sales": 124358734000 },
    …
  ]
}
항목뜻
w2 ~ w52~5등 당첨 게임 수
a2 ~ a52~5등 1게임당 당첨금 (원, 세전)
sales그 회차 판매액 (원)

두 파일에는 설명용 항목(source, note)이 더 있을 수 있습니다. 회차는 round 로 맞춰 합치면 됩니다.

예시 코드

JavaScript

const res = await fetch('https://www.lottodraw.kr/lotto-data.json');
const { draws } = await res.json();
const latest = draws[0];
console.log(latest.round, latest.numbers, latest.bonus);

Python

import requests

draws = requests.get('https://www.lottodraw.kr/lotto-data.json', timeout=10).json()['draws']
latest = draws[0]
print(latest['round'], latest['numbers'], latest['bonus'])

이용 조건

  • 무료입니다. 개인 · 상업 목적 모두 가입이나 신청 없이 쓰실 수 있습니다.
  • 쓰시는 화면이나 글에 출처로 lottodraw.kr 과 링크(https://www.lottodraw.kr/)를 보이게 남겨 주십시오. 아래 문구를 그대로 붙여 넣으셔도 됩니다.
  • 원자료는 동행복권이 발표한 추첨 결과입니다. 옮기는 과정에서 잘못이 생길 수 있으니, 당첨 확인처럼 중요한 일은 동행복권 공식 결과로 확인하십시오. 이 자료를 써서 생긴 일에 대해 lottodraw.kr 은 책임지지 않습니다.
  • 항목을 빼거나 이름을 바꿔야 할 때는 이 페이지에 먼저 알립니다. 새 항목은 알림 없이 더해질 수 있습니다.
  • 사이트 화면(회차별 당첨번호 표 등)을 긁어 가기보다 위 파일을 받으시는 편이 빠르고 정확합니다.
