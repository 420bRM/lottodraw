# 글자 · 행간 · 회색 · 간격 규칙 (2026-11-20)

사장님이 정한 기준: **글자 크기 5단계, 회색 글자는 정한 자리에만, 간격은 한 숫자(4px)의 배수.**
새 CSS · 화면을 만들거나 고칠 때 이 규칙을 따르고, 끝나면 `node tools/ui_check.cjs` 가 **어긋남 0곳**인지 본다.

이 사이트(번호 생성기 · 통계 표 · 판매점 지도 · LottoHex · 블로그 · 한국어/영어)에 맞춘 값이다.
본문은 원래 쓰던 15px 를 그대로 두고, 지도 · 칩처럼 촘촘한 곳의 9~11.5px 글자를 12px 로 올렸다.

## 1. 글자 크기 — 다섯 단계 (`css/site.css` 맨 위 `:root`)

| 변수 | 크기 | 쓰는 자리 |
|---|---|---|
| `--fs-1` | 22px | 큰 제목 — 쪽 제목(h1), 로고, 핵심 큰 숫자 |
| `--fs-2` | 18px | 제목 — 구역 · 카드 · 창 제목, 타일 숫자, 카운트다운 |
| `--fs-3` | 15px | 본문 — 이어 읽는 글(블로그 · 통계 설명 · 안내 문단), 소제목(h3, 굵게) |
| `--fs-4` | 13px | 보조 — 단추 · 칩 · 메뉴 · 표 · 짧은 안내 |
| `--fs-5` | 12px | 작은 글 — 라벨 · 날짜 · 단위 · 각주 · 지도 칩 · 배지. **이보다 작게 쓰지 않는다** |
| `--fs-input` | 16px | 입력칸(input · textarea)만 — 16px 밑이면 iOS 가 입력할 때 화면을 확대한다 |

- 값은 숫자로 쓰지 말고 변수로: `font-size: var(--fs-4)`, `font: bold var(--fs-4)/var(--lh-tight) var(--font)`.
- 휴대폰에서 제목이 너무 길어지면 그 제목만 **한 단계 낮춘다**(예: `--fs-1` → `--fs-2`). 본문 · 단추는 휴대폰에서도 같은 단계.
- 소제목은 크기 대신 굵기로 구분한다(h2 = `--fs-2`, h3 = `--fs-3` 굵게).
- `em` · `%` 크기는 쓰지 않는다(글 속 `code` 만 예외).

## 2. 행간 — 두 가지

| 변수 | 값 | 쓰는 자리 |
|---|---|---|
| `--lh-tight` | 1.3 | 한 줄 라벨 · 제목 · 단추 · 칩 |
| `--lh-body` | 1.6 | 이어 읽는 글(body 기본값) |

- `line-height: 1` 은 공 · 기호(×, ＋) · 아이콘처럼 상자 크기가 정해진 곳에만.
- px 행간은 고정 높이 한 줄(배지 · 흐르는 글)에만, 예외 주석을 단다.

## 3. 회색 글자 — 작은 단계 · 정한 자리에만

회색 = `--muted` · `--faint`(낮 #555 · #888 무렵, 밤 #9ba5b4 · #7d8797).

- **쓰는 자리**: 라벨, 날짜 · 회차 옆 날짜, 단위(원 · 회), 각주 · 출처, 빈 화면 안내("아직 없습니다"), 비활성 상태.
- **크기**: `--fs-4` · `--fs-5` 에서만. 그보다 큰 글자는 `--text` / `--fg` 를 쓴다.
- **쓰지 않는 곳**: 숫자 값(당첨금 · 횟수 · 순위), 본문 문단, 링크, 단추 글자.
- 큰 기호(×, ＋, →)는 글자가 아니라 그림으로 보고 예외(주석)로 둔다.

## 4. 간격 — 4px 의 배수

- `margin` · `padding` · `gap` · `min-height`(단추 · 칩 높이)는 **0 · 4 · 8 · 12 · 16 · 20 · 24 · 28 · 32 …** 만.
- 예외(점검 도구가 세지 않음): 선 굵기(`border`), 음수 값(겹치기 · 위치 맞춤), `top/left` 같은 위치 값,
  화면 높이를 계산하는 `calc()`(예외 주석).
- 좁은 휴대폰(≤ 380px)에서 자리가 모자라면 글자를 줄이지 말고 여백을 한 단계(4px) 줄인다.

## 5. 예외 — 크기를 계산하는 곳

아래는 다섯 단계 밖이어도 된다. 선언 바로 뒤에 `/* 예외: 이유 */` 를 단다(점검 도구가 예외로 센다).

| 자리 | 까닭 |
|---|---|
| 번호 공(`.ball` · `.mball`) 안 숫자 | 원 크기에 맞춘다 |
| 그래프(SVG) · 45칸 눈금 · 지도 축척 · 지도 위 그림 글자 | 그림 속 글자, 칸 폭에 맞춘다 |
| 지도 글자(MapLibre `text-size`) · LottoHex 판 | 지도가 줌에 따라 계산한다(CSS 밖) |
| 연출 숫자(이용권 가격, LottoHex 점령 효과, 404) | 장식 |
| 기호(×, ＋, →, ★, 🔒) | 글자가 아니라 그림 |
| 인쇄(`@media print`, pt 단위) | 종이 기준 |
| 공유 그림(canvas 1200×630) · 광고 그림(`ads/`) | 그림 파일 |

## 6. 점검 도구

```
node tools/ui_check.cjs           # 어긋난 곳 목록, 하나라도 있으면 1 로 끝남
node tools/ui_check.cjs --stat    # 개수만
node tools/ui_check.cjs --exempt  # 예외로 둔 곳까지
```

보는 곳: `css/*.css`, 맨 위 · `blog/` 의 `*.html` 안 `<style>`, `tools/build-*.js` 의 `<style>` · `…STYLE` 상수.
JS 가 그리는 그림(canvas · SVG 속성)과 지도 스타일은 보지 않는다.
