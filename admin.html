입금 알림 연결 (자동 입금 확인)한 번만 설정

휴대폰이 은행 입금 알림을 받으면 그 내용을 아래 주소로 그대로 넘겨주게 해 두면, 서버가 금액으로 주문을 찾아 새벽에도 바로 키를 발급합니다. 휴대폰은 켜져 있고 인터넷만 되면 됩니다.

보낼 주소
머리글
Authorization: Bearer (열쇠)
열쇠
안드로이드 (MacroDroid)
  1. Play 스토어에서 MacroDroid 설치 → 알림 접근 권한 허용, 휴대폰 설정 → 애플리케이션 → MacroDroid → 배터리 → 제한 없음. 무료 버전은 7일마다 "기간 연장"을 눌러야 해서, 놓치면 자동 확인이 멈춘다 — 프로(1회 결제)를 권장
  2. 은행 앱에서 입출금 알림(푸시) 켜기 — 알림에 금액과 보낸 사람 이름이 보여야 한다
  3. 새 매크로 → 발동 + → 위 돋보기로 알림 검색 → 알림 수신 → 앱: 판매 계좌의 은행 앱, 내용에 입금 포함
  4. 동작 + → 돋보기로 HTTP 검색 → HTTP 요청 → 방법 POST, URL 은 위 "보낼 주소", 헤더 Authorization = Bearer 열쇠(한 칸 띄움), 본문 text/plain 에 매직 텍스트 버튼으로 알림 제목과 알림 텍스트 넣기. 요건은 비워 두고 저장
  5. 매크로 하나 더: 발동 + → 날짜·시간 → 정기적 간격 6시간, 동작은 같은 HTTP 요청에 본문만 ping
  6. ping 매크로를 열고 ⋮ → 동작 테스트를 누르면 1~2분 안에 이 카드가 "연결됨"으로 바뀐다
아이폰 (단축어 + 은행 입출금 문자 알림)
  1. 은행 앱에서 입출금 문자(SMS) 알림 신청 — 아이폰은 앱 푸시를 넘길 수 없어 문자를 씁니다
  2. 단축어 앱 → 자동화 → 새로 만들기 → 메시지 → 보낸 사람: 은행 번호, 메시지에 입금 포함 → 즉시 실행
  3. 동작: URL 콘텐츠 가져오기 → 위 주소, 방법 POST, 헤더 Authorization = Bearer 열쇠, 요청 본문 JSON → 키 text = 단축어 입력(받은 메시지)
  4. 자동화 하나 더: 시간 → 매일 여러 번(예: 0·6·12·18시) → 같은 동작에 text 값만 ping

설정 뒤 1~2분 안에 위 상태가 "연결됨"으로 바뀌면 끝입니다. 끊기면(13시간 신호 없음) 텔레그램으로 알려 드리고, 그동안 구매 화면은 "판매자 확인 뒤 열림"으로 바뀝니다. 다른 입금(월급 등)도 넘어오지만 이용권 금액이 아니면 무시합니다 — 가능하면 판매 전용 계좌를 쓰세요.

키 직접 발급다른 곳에서 판 경우, 보상, 테스트

키 정지 · 정지 해제

정지한 키는 방문자 브라우저가 다음 확인 때(최대 12시간 안) 잠깁니다. 주문으로 판 키는 위 목록의 "환불 처리"를 쓰면 주문 상태도 같이 바뀝니다.

설정 상태

    처음 한 번: 이용권 키에 서명할 키를 만듭니다. 만든 뒤에는 바꾸지 않습니다 — 바꾸면 이미 판 키가 모두 무효가 됩니다.

    공개키를 js/premium-config.js 의 publicKeyJwk 에 붙여 넣으면 방문자 브라우저가 공개키를 서버에 묻지 않습니다 (선택).

    백업 값은 키를 새로 만들 수 있는 비밀입니다. 비밀번호 관리자나 GitHub Secret LICENSE_PRIVATE_JWK 에만 넣으세요. Cloudflare 저장소(KV)를 잃어도 이 값이 있으면 판매한 키가 살아납니다.
